# CSV файл для устройств LoRaWAN симулятора

Этот файл содержит конфигурацию устройств для симуляции LoRaWAN сети.

## Структура файла

CSV файл использует разделитель `;` (точка с запятой) и содержит следующие поля:

| Поле | Тип | Описание | Обязательное |
|------|-----|----------|--------------|
| Name | string | Имя устройства | Да |
| Profile | string | UUID профиля устройства | Да |
| DevEUI | hex string | Уникальный идентификатор устройства (16 символов) | Да |
| AppKey | hex string | Ключ приложения (32 символа) | Да |
| Join EUI | hex string | Идентификатор Join Server (16 символов) | Нет |
| Processor ID | uint8 | ID процессора для CPU info payload | Нет |
| Description | string | Описание устройства | Нет |
| Active | bool | Активно ли устройство | Нет |

## Пример содержимого

```csv
Name (string);Profile;DevEUI (hex string);AppKey (hex string);Join EUI (опционально) (hex string);Processor ID (uint8);Description (string);Active (true/false)
lorawan-emulator-01;98e37811-de41-4da7-9440-f3c8fb35fbb9;7700000000000001;a1b2c3d4e5f678901234567890abcdef;0000000000000000;1;LoRaWAN сенсор 1;true
lorawan-emulator-02;98e37811-de41-4da7-9440-f3c8fb35fbb9;7700000000000002;b2c3d4e5f678901234567890abcdefa1;0000000000000000;2;LoRaWAN сенсор 2;false
```

## Поле Processor ID

Поле `Processor ID` определяет, какой процессор будет использоваться для формирования payload:

- **Число (1, 2, 3, ...)**: Устройство будет читать информацию о соответствующем процессоре из `/proc/cpuinfo`
- **"none" или пустое**: Устройство будет использовать значения по умолчанию (processor=0, cpu_mhz=0.0, vendor_id="unknown")

## Формат payload

Payload формируется как байтовый массив размером 25 байт:

1. **Processor ID** (1 байт): ID процессора
2. **CPU MHz** (4 байта): Частота процессора в МГц (float32, little-endian)
3. **Vendor ID** (20 байт): Производитель процессора (строка, дополненная нулями)

## Примечания

- DevEUI и AppKey должны быть валидными hex-строками
- Join EUI опционально, если не указан, используется значение по умолчанию
- Processor ID опционально, если не указан или равен "none", используются значения по умолчанию
- Устройства с Active=false не будут участвовать в симуляции
